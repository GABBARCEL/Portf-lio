Site de doações

Um site simples, esse é um projeto full-stack onde temos o frount-end feito em JavaScript e o back-end feito em python com framework Flask. Ao preencher os campos e precionar o botão, envia as informaações via API para o back-end, onde os dados são processados. O retorno é um payload em pix, que o frount-end posiciona na tela (ao clicar ele copia para a área de transferência) e também cria um QRcode com a chave pix. Esse projeto desenvolveu minha criação e uso de API's e também meu JavaScript, além de melhorar como estruturo meu projetos.
